# 🤖 Rule-Based AI Chatbot

A simple rule-based AI chatbot developed in Python as part of **DecodeLabs Artificial Intelligence Project 1**.

## 📌 About the Project

This project demonstrates the basic concept of a rule-based chatbot. The chatbot uses predefined rules and `if-elif-else` conditions to identify user inputs and provide appropriate responses.

The chatbot continuously interacts with the user until the `bye` command is entered.

## 🎯 Project Objectives

- Handle greetings and exit commands
- Use `if-elif-else` logic for responses
- Run the chatbot in a continuous loop
- Understand basic AI concepts and decision-making logic

## ✨ Features

- Greeting responses
- Basic conversation
- User help command
- Name identification
- Thank-you response
- Exit command
- Unknown-input handling

## 🛠️ Technologies Used

- Python
- Conditional Statements
- While Loop
- User Input
- String Methods
